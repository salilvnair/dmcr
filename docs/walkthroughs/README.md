# DMCR walkthroughs

Step-by-step walkthroughs of DMCR Web, each step with the real screen it shows. Download a page and open it in a browser (GitHub shows `.html` files as source).

| Walkthrough | What it covers |
|---|---|
| [QuickStart](quickstart-walkthrough.html) | The shortest path: two DBAs on one repository, projects A and B, a conflict that refuses the deploy until it is merged, A kept off prod, both to test and only B to prod. It starts with setting up test and prod on a local PostgreSQL from DBeaver: admin users, schemas and app roles. |
| [Light](light-walkthrough.html) | The everyday flow: setup, three projects, a clash between two changes, releases deployed to test and prod, and importing existing changes. |
| [Full](full-walkthrough.html) | Everything: every change kind, releases, repeatables, danger rules, hotfixes, tags, drift, rollbacks and imports. |
